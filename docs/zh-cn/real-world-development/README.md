通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将迭代执行变更规划、代码编写、行为测试、拉取请求审查以及使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为以开发者为主题的棋盘游戏提供众筹服务。团队待办事项已作为 GitHub 议题创建，等待你领取。其中既有筛选和分页等功能需求，也有无障碍和编码规范等质量改进。

## 选择开发环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合自己开发方式的环境。每个研讨会都有各自的环境设置，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright 模型上下文协议 (MCP) 服务器、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot 应用][app]

并行运行多个代理会话、切换会话模式、在画布中协作，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云代理][cloud]

将 GitHub 议题分配给异步代理、指导其工作、监控进度，并审查代理创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。

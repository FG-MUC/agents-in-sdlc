GitHub Copilot CLI には、操作に使える多くのスラッシュコマンドが用意されています。これらのコマンドから、高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などを使いました。ほかの便利なコマンドも確認しましょう。

このレッスンでは、次の操作を行います。

- `/context` と `/compact` を使い、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` を使い、利用可能なモデルを確認します。
- `/share` でセッションをエクスポート、共有する方法を学びます。
- 並行作業、ワークツリー、クラウドエージェントへの委任に使える任意のコマンドを確認します。

## シナリオ

CLI の主要なワークフローが完了しました。ここでは、コンテキストの管理、モデルの切り替え、セッションの共有、[Copilot クラウドエージェント][about-cloud-agent]への任意の委任など、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクでは、モデルの最大コンテキスト ウィンドウに達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドを使ってコンテキストを確認したり、自分で圧縮したりできます。

1. Codespace に戻り、Copilot CLI が起動していない場合はリポジトリのルートから起動します。
2. 次を入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域に分割されたコンテキストを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力し、結果を比較します。会話が短い場合は、大きな違いがないこともあります。

> [!NOTE]
> Copilot CLI はコンテキスト ウィンドウが埋まると自動的に圧縮します。タイミングを自分で選ぶ場合は `/compact` を使います。関係のない別のタスクに切り替えて新しい会話を始める場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者ごとに好みも異なります。Copilot CLI では、利用可能なモデルを表示して選択できます。

1. 次を入力します。

   ```plaintext
   /model
   ```

2. 使用可能なモデルと使用状況の情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力し、学んだことを共有すると、AI ツールの活用方法を改善できます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、使用中のバージョンにある `/share` のオプションを確認します。
2. セッションを共有する場合は、ローカルの Markdown ファイルに出力する `/share file` など、適切な保存先を選択します。
3. エクスポートした内容を送信または公開する前に確認します。エクスポートにはプロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は任意です。チームが共有する予定のないリポジトリや会話の内容は公開しないでください。

## 任意: 作業を拡大する、または委任する

主要なワークショップは完了しました。Copilot CLI には、より大きなタスクに使えるコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに分割し、並行して実行します。
- `/worktree` は、別のタスク用に分離された Git ワークツリーを作成します。
- `/delegate` は、タスクを Copilot クラウドエージェントに送信します。クラウドエージェントは非同期に作業し、プルリクエストを作成する場合があります。

これらのコマンドは追加のワークツリーやリモート作業を作成することがあるため、使用は任意です。試す場合は、新しい範囲の明確なタスクから始め、通常のワークフローで結果をレビューしてください。非同期エージェントの作業について詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進みます。
